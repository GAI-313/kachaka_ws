# Kachaka の安全機能を無効にする方法

> [!WARNING]
> 　ROS 経由で Kachaka を制御するときに安全機能を無効にすると，予期せぬ移動停止などを回避できる場合があります．一方で安全性が低下し，ロボットが障害物に接触したり，段差から転落したりする可能性があります．十分に安全を確認できる環境でのみ使用してください．<br>
> 　**常用使用に戻す場合は，無効にした安全機能を元の設定へ戻し，有効にすることを推奨します．**
